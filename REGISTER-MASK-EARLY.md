# Register-mask plus earlier dataset prefetch

Combines register-held scratchpad addresses and ternary loop masks with the earlier dependency-safe dataset prefetch experiment. Rounding-store scheduling and VAES-256 are excluded.

After generating a VM program, find the later of the final writers of the two dataset address input registers. Every CBRANCH marks all registers used at its end, so this insertion point also follows the last branch. If at least 64 generated bytes remain, insert a 25-byte address calculation and PREFETCHNTA hint there. The address uses high32(rbp) XOR the two low register halves, masked by CacheLineAlignMask, matching the normal next dataset address calculation. Scratch temporaries RAX and RDX are used; VM registers and memory contents are unchanged.

The original later prefetch remains. This adds an early hint rather than removing the later one. Light mode and V2 prefetch mode do not get the insertion. Register-pointer AVX-512 guards remain unchanged. Branch targets inside the preceding program need no relocation because the insertion follows its last branch; final loop displacement is generated after insertion. Existing CFROUND elimination occurs before insertion.

The experiment may hide dataset latency when enough independent tail work remains, but adds instructions and cache hints. Speed and power improvement are unproven.

With the pool miner stopped:

    python3 run-experiment.py register-mask-early

The separate Alpine build uses pinned upstream source, generic settings and AES prefetch distance 7168. The runner checks the 1M checksum 898B6E0431C28A6B and never installs a miner or changes startup.

Local validation: full production build passed. 512 generated VM programs at 32 iterations matched the forced original path in registers, full 2 MiB scratchpad and final MXCSR. The test exercised 225 early-prefetch insertions and verified register-pointer selection and fallback restoration. Canonical patch replay, builder shell syntax and runner compilation passed. Test instrumentation is excluded from production.

Production local 250K rx/0 checksum 7D6054757BB08A63 passed. Local timing does not establish target Ryzen speed or wall power.
