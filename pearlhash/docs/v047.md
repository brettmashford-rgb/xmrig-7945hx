# v0.0.47: direct resident-axis scanning (offline experiment)

The scanner reads canonical row/column maps directly, removing the v045
GPU descriptor-builder launch and its intermediate writes. One stream,
4096 tiles per window, eight-byte window status upload. Maps/targets are
uploaded once per nonce. The descriptor allocation and guards are retained.
ResidentBackend defaults to ResidentDispatch; v046 live behavior stays unchanged.
The direct backend is selected only by the new offline tools.

The 24-argument ABI replaces slot 5 with row axes and appends column axes,
row count, column count and first tile in slots 20 through 23. Bounds/domain
checks precede indexing. The tile body starting at bool invalid is verbatim
the validated cached-A scanner. No hashing, target, nonce or proof rule changes.
Complete queue candidates still undergo independent CPU verification;
overflow and stale work preserve existing NonceSearch ownership/cursor rules.

The installer requires completed v046 mining-result.json (joined worker,
resident-maps-one-stream-v046, no error), verifies 15 dependency manifests and
all their files, and reads the CPU library pin from the installed v031 manifest.
It installs source and readable sm_120 PTX without a toolkit or pip on the rig.
No login capture is needed: all v047 jobs are fresh synthetic offline jobs.

check_direct_job.py gates timing on four 4096-query transcript windows versus
actual v045 dispatch (first, row crossing, middle, end), canonical CPU descriptor
serialization, eight independent CPU samples, eighteen target/queue cases,
a populated 67-query overflow, a fresh V3 proof passed to the official CPU
verifier, retained odd miss windows and stale rejection.

compare_direct_loops.py compares resident-v045 against direct-v047 on one
synthetic production nonce/target and identical tile ranges. Both advance(4096).
Twenty alternating-order rounds time 65536 tiles per mode per round, with
uninstrumented timings and a separate driver call/byte diagnostic. Setup/cache
cost is reported separately. Direct is preferred only for a greater than 3%
reduction in elapsed time (speedup > 1/.97). Output: DIRECT COMPARISON and
DRIVER COUNTS; full report: direct-comparison.json.

Development checks: 27 targeted host tests pass. NVRTC 12.9.86 compute_120,
C++17 builds the 654498-byte readable PTX with SHA256
9b1da0c6879d4fe91907f151ab0fa02267e7c3eca8c24f3c9a473b65b6e856f4.
The new entry has zero CTA barriers. Hardware correctness, fresh official proof
verification and speed measurements must run on the rig; no GPU result is
claimed from host tests. Pool acceptance of this independent miner remains
unproven; status acknowledgements are not shares.

No pool connections, live integration, third-party miner code, fee, clock,
CPU XMRig, persistent service definition or autostart changes. The Termius
wrapper schedules a 15-minute WildRig fallback before pausing it, bounds the
experiment runtime, then explicitly starts pearl.service on success or failure.
