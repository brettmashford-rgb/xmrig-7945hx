# v0.0.48: pack status and every guard into one readback

The completed v047 rig comparison measured 468079 tiles/s for v045 resident
maps and 474883 tiles/s for direct maps (1.45% faster). The 3% elapsed-time
adoption margin retained v046's resident-map live path. Both modes made 400
DtoH calls per 65536-tile diagnostic: 25 calls per 4096-tile window, consisting
of one eight-byte status read and 24 separate sixteen-byte guard reads.

v048 is an offline experiment. A small collector, ordered after the scanner
on its existing stream, gathers status, generation/first/count and every
original guard into one buffer. All 24 original endpoints are preserved, plus
four guards for the pointer table and snapshot buffer. Each empty window reads
504 bytes in one DtoH call. Pointer-table/setup uploads happen once per nonce;
window upload remains the eight-byte status reset. This reduces call count,
not bytes: baseline 392 bytes/window versus packed 504 bytes/window.

The host checks output sentinels, all 28 gathered sentinels and exact window
identity before trusting queue status. Only populated candidate records and
requested audit transcripts cause additional copies. Complete candidate queues
remain independently CPU-verified before proof construction. Overflow/stale
handling, retained ownership, cursor rules and all scanner math stay unchanged.
A failed guard check is fatal to its dispatch. No guard sampling or skipped
checks. Two variants share this collector: validated resident descriptor-builder
scanning, and v047 direct-map scanning. Existing sources/live defaults are not
modified. The new kernel includes the established entries unchanged and adds
only resident_guard_snapshot, with no CTA barriers.

Rig preflight checks both variants separately against actual v045 dispatch:
eight total full 4096-query transcript/CPU descriptor windows, sixteen independent
CPU transcript samples, 36 target/queue cases, two populated 67-query overflow
cases, all 56 guard endpoints via deliberate sentinel corruption, two fresh
V3 proofs through the official verifier, retained odd miss windows and stale
rejection. A new dispatch is made for each deliberate corruption, then its
sentinel is restored and its allocations freed. Payload bytes are untouched.
Only full success enables comparison.

Comparison uses one fresh synthetic production job/nonce/target, identical
ranges, advance(4096), 65536 tiles per round/mode, and three retained caches.
24 rounds repeat every permutation of the three modes four times, balancing
all order positions. Initial context/JIT and shared commitment/nonce setup are
excluded; mode cache/setup times are reported. Primary timing is uninstrumented.
A separate diagnostic must measure 400/16/16 DtoH calls and 32/48/32 kernel
launches respectively for baseline/packed resident/packed direct. Preference
requires greater than 3% elapsed-time reduction versus baseline. Saved output:
packed-comparison.json; terminal labels PACKED COMPARISON and DRIVER COUNTS.

Development checks: 46 targeted host tests pass, including the actual C++
collector helper byte layout, every guard, queue verification, stale windows,
read count, exact ranges/balanced timing order and installer gating. Two
NVRTC 12.9.86 compute_120/C++17 builds reproduce identical readable PTX:
657078 bytes, SHA256
265baca48f8352b7b06013c28f2361e816a539f6e01d513f1cfeb2bae687c118.
Hardware correctness/proof/performance remain pending until the rig run.

Installer requires completed v047 proof/comparison and verifies 16 dependency
manifests/files. CPU library pin is read from installed v031 metadata. No rig
compiler/toolkit/pip required. No pool connection or login capture needed.
No fee, wallet, header, nonce, seed, proof or capture is published. No third-party
miner code. Genuine independent-miner pool acceptance remains unproven.

The launcher schedules a 15-minute WildRig fallback before stopping pearl.service,
bounds the experiment to 13 minutes, and explicitly restarts WildRig afterward.
CPU XMRig, clocks, permanent service definitions, pools and autostart are preserved.
