# v071: partitioned transcript folds

Independent offline experiment using the rig-validated v068 advancing-pointer kernel as control. No v069/v070 installation or result is needed. v066 remains the last validated live worker. No whole-miner speed or accepted-pool-share claim is made.

## Work reduction

v068 folds four independent per-tile values across a warp at every 128-K checkpoint using four five-shuffle butterfly reductions. v071 first folds the two low lane bits for all four values (eight shuffles), assigns one tile to each thread position, then folds the three remaining lane bits once (three shuffles). Eleven replaces twenty fold shuffles at full production checkpoints, a 45% reduction in this operation. B reconstruction and all six MMA instructions remain unchanged.

Each lane holds two transcript words for its assigned tile, covering sixteen slots across eight lane groups. The helper maps each output tile/slot back to its exact word for the existing concurrent gather/hash/emission epilogue. It preserves rotation-by-13 and every repeated slot update. All lanes participate in the partitioned reduction even for partial quartets; existing active flags govern final emission. No new block barrier, allocation, map, traversal, query order, target rule or queue format is introduced.

The second candidate changes only the four fold helper calls in the v068 pointer kernel to full-mask native XOR reductions. v063's native reduction previously fell below promotion margin on a different two-tile scanner. This tests it with the current four-tile pointer scanner and concurrent epilogue; it is not a speedup claim or adoption of the rejected v067 epilogue.

## Compiled evidence

Own-source NVRTC 12.9.86, compute_120/C++17; two byte-identical PTX builds. Each entry retains 24 arguments, six MMA instructions, 12 global load instructions and five wide multiplies in its static K loop, with no CTA barriers. Static K-loop shuffle counts are 28 for the actual v068 control, 19 for the partitioned candidate, and eight plus four native reductions for the native candidate. Eight of the shuffle instructions belong to B reconstruction each K step; the fold is conditional every fourth step. These instruction counts do not predict whole-kernel throughput. Compiled registers/local storage and actual speed require the rig.

## Correctness and measurement

The real portable ownership/selection/update helpers are compiled with undefined-behavior sanitizer and compared with four independent XOR/rotation references at all 256 checkpoints, across all sixteen active-tile masks, zero/all-one/high-bit/random inputs and repeated transcript slots: 655,360 word comparisons. Source contracts preserve the v068 guards, B/A loads, MMA, final pointer handling and emission. Native code differs only in fold helper names. The 208-test regression suite also covers ABI/PTX, independent dispatch/guard/stale/overflow handling, both installer proof gates and full simulated benchmark success/failure paths. Simulated pool replies in unrelated runner tests are not real acceptance evidence.

Each rig candidate must pass two fresh production nonces, eight full 4,096-query transcript windows against the compiled packed control, sixteen independent CPU transcript samples, eighteen target/queue cases, a populated 67-query overflow, all 28 allocation-guard faults, retained odd windows and stale rejection. Two fresh V3 proofs per candidate must pass the installed official CPU verifier before timing.

Three paths then retain independent A/B/geometry owners in one context. Twenty-four rounds use all six mode orders evenly, 65,536 identical canonical tiles per round, 1,572,864 unique timed tiles per mode, and 4,096-tile advance windows. Primary timing includes the existing search/guard/readback contract and excludes initial setup/JIT and nonce/commitment preparation. Separate driver diagnostics require sixteen resets, 32 launches, sixteen stream waits and sixteen readbacks totaling 8,064 bytes per mode, without search-time HtoD or context-wide waits. Prefer a candidate only after more than 3% median elapsed reduction over the actual v068 control.
