# v0.0.46: bounded resident-map live worker

Integrates the rig-validated v045 resident backend into the bounded miner with
explicit `--cache-a --resident-maps`. Reuses v045 PTX/source and v039 GPU constant
commitment unchanged. V045's controlled same-nonce one-stream comparison measured
355359 versus 475516 tiles/s (33.8% higher); this is not a promised live gain.
Per 65536-tile diagnostic, upload traffic was 19398784 versus 128 bytes, excluding
axes/target setup. Resident upload and planning setup is still paid per nonce.

The worker calls the SAME new_resident_search factory already validated by v045
fresh V3 proof, canonical descriptor/transcript cases, target/queue checks, retained
windows and stale rejection. One stream, advance(4096), full production domain
8388608 tiles per nonce. No duplicate FastPlan construction. Each nonce owns its
A cache, resident axes/target buffer and guarded dispatch buffers. Existing
NonceSearch overflow retry, global candidate IDs, cursor credit and stale job
cancellation remain. Complete candidates still go through independent CPU math,
commitment openings/proof construction and the existing submission gate.

`--resident-maps` and `--two-streams` are mutually exclusive and require
`--cache-a`; defaults preserve existing explicit backend selections. Agent and
worker identify v046. Report scan_backend is resident-maps-one-stream-v046 when
selected. Resident descriptor windows are printed; these count scan dispatches,
including any full-queue retries, not a mining rate or accepted shares.

One pool connection to the existing endpoint, up to 300 seconds, at most one new
custom share, no automatic reconnect/retry. Assigned extranonce as worker_nonce
remains a hypothesis until a genuine custom share is accepted. Status report ACKs
remain separate from share verdicts. No captures or old shares are replayed.

Installer verifies all pinned installed dependencies and local CPU library,
completed v045 correctness/proof report and a >3% controlled timing win. It reuses
that exact validated backend/module without repeating old GPU/proof tests. New
source is installed separately into v046; v045 and older directories stay intact.
No permanent service is installed or changed. The Termius wrapper pauses WildRig,
schedules a 15-minute fallback restart, then restores it on completion. XMRig and
clock settings remain unchanged.

Host tests use mocked mining math/GPU and a scripted synthetic connection to
check backend selection, nonce rollover, candidate/proof/send orchestration,
metadata and cleanup; they are not live pool acceptance evidence. Installer
tests reject absent/failed prior gates and preserve one bounded endpoint/run.
