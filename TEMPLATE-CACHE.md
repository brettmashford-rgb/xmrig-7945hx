# Cache the selected loop-load template between JIT programs

Based on register-mask. Changes host-side JIT generation only: the loop-load template is copied into the code buffer only when its selected kind changes. Stable normal full-memory rx/0 reuses the existing register-pointer/ternary-mask template. No extra VM planner or opcode-dispatch experiment is included.

The constructor records its initial original/XOP template. The prologue selects normal, XOP or register-pointer kind as before and copies on a kind transition. Superscalar and dataset-init generation invalidate the cached kind. Mode transitions restore the original template as needed. Code sizes and all subsequent body/epilogue generation stay unchanged.

The old unused uint32_t imul_rcp_storage_used field is renamed to cachedLoopLoadKind, keeping its type and position. The selected RCP baseline no longer uses reciprocal storage slots; its former per-program zero reset is removed. No new JIT object field or VM layout expansion is introduced. The existing reciprocal pointer is retained for dynamic eMask placement.

Steady rx/0 avoids rewriting 118 unchanged executable bytes for each of eight generated programs per hash. This is 944 bytes of avoided logical writes per hash, not DRAM bandwidth savings. A short branch and state check replace each repeated memcpy. The same generated VM instructions are retained. Speed and power benefit are unproven.

Local validation: two runs of a 512-program native harness matched generated bytes exactly against forced always-copy mode; full register files, 2 MiB scratchpads and final MXCSR matched at 32 iterations. Pointer selection and light/non-full/V2 fallback restoration passed. Ten repeated stable-mode compilations were confirmed to perform no template copies. Six alternating-order warm-page compile/execute batches at 2048 iterations also matched state. Timing on the shared Intel host varied strongly; no speed claim is made. Canonical patch replay, builder syntax and runner compilation passed.

Prepared Alpine command, after publication:

    python3 run-experiment.py template-cache

The builder applies the existing published register-mask baseline plus a JIT-only delta, verifies the combined source against a temporary local reference clone, and uses separate source/output trees. Generic settings, 7168-byte AES prefetch distance, no installation or startup changes. The runner requires the 1M checksum 898B6E0431C28A6B.

Production local 250K rx/0 checksum 7D6054757BB08A63 passed. This shared-host run is a correctness result, not target speed or power evidence.
